# Recurly

A subscription management mobile app built with **React Native, Expo, and TypeScript**.

## Features

- 🔐 Authentication with Clerk
- 💳 Create and manage subscriptions
- 📊 Analytics with PostHog
- 📱 iOS & Android support
- 🧭 File-based routing with Expo Router

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Clerk
- PostHog

## Getting Started

```bash
git clone https://github.com/Mohsnwy/react_native_recurly.git
cd react_native_recurly
npm install
```

Create a `.env` file:

```env
EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY=your_key
EXPO_PUBLIC_POSTHOG_PROJECT_TOKEN=your_token
EXPO_PUBLIC_POSTHOG_HOST=your_host
```

Start the app:

```bash
npx expo start
```
